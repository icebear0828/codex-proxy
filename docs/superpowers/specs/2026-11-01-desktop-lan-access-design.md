# 桌面端局域网访问开关

## 目的与范围

普通用户可以从桌面端设置允许同一局域网的其他设备使用 Codex Proxy，无需手动编辑 local.yaml。复用现有 Preact 设置页、管理接口和配置覆盖机制。本次为小改动，单 Agent 实施。

## 方案比较与选择

- 简洁开关：仅表达本机访问与允许局域网访问，复用现有端口设置，操作最少。用户已选择此方案。
- 访问范围选择器：增加自定义网卡地址，灵活但超出主要使用场景，暂不采用。

## 用户操作

- 在桌面端“设置”的服务配置区域添加“允许局域网访问”，默认关闭。
- 开启映射为 server.host: 0.0.0.0，关闭映射为 127.0.0.1；修改后沿用逐项保存方式。
- 保存后明确提示“已保存，完全退出并重新打开应用后生效”；不自动停止服务，不添加自动重启能力。
- 展示运行中的访问状态与待重启状态，不能将已保存的配置误报为已经生效。
- 开启且生效后展示本机非回环 IPv4 的访问地址，可复制 API 基础地址 http://<IP>:<实际端口>/v1；多个地址逐项显示，不自动猜测哪张网卡可达。地址仅供连接使用，不承诺连通性。没有地址时提示检查网络。
- 提示其他设备需在可达网络内，连接失败时检查系统防火墙是否允许应用在专用网络接收入站连接；不自动修改防火墙。

## 边界与兼容

- 0.0.0.0 监听全部 IPv4 网卡，并不强制限制来源为同一子网。提示仅在可信网络使用，实际来源范围由防火墙决定。
- 开启时后端要求已配置非空且非默认 pwd 的管理密钥，未满足时引导用户通过现有密钥设置修改；建议使用强随机密钥，不自动替换任何密钥。
- 沿用现有管理权限校验；返回网卡地址的接口同样受保护。保持 trust_proxy 配置不变，不改变 API 或面板鉴权规则。
- 已有自定义 host（例如绑定某张网卡或 IPv6）的用户，显示“当前使用自定义监听地址”，保留原值，直到用户主动保存本开关；不能加载页面即覆盖。
- 保留其他 local.yaml 配置。保存失败展示错误，不显示成功。复用现有中英文翻译机制。
- 此功能入口面向桌面端，不扩展为通用配置文件编辑器，不增加公网访问、IPv6 设置或网络诊断功能。

## 实现边界

扩展服务设置接口及共享 hook，提供持久化的监听配置、运行中的监听状态和可用 IPv4 地址；前端复用 GeneralSettings 与 SettingItemControl。运行状态来自实际 ServerHandle，避免端口被占用回退时展示错误地址。具体字段命名及模块划分交由实施计划确定。

## 验收

1. 默认保持仅本机访问；开启、保存、重启后实际监听全部 IPv4，关闭后恢复回环监听。
2. 开启前校验密钥，鉴权和其他配置保持原有语义。
3. 保存前后、重启前后状态准确；实际端口与地址可复制，多网卡和无地址状态可理解。
4. 自定义 host 不被隐式覆盖，保存失败不误报成功。
5. 对配置读写、密钥前置校验、运行状态及 UI 状态执行针对性测试；不发送真实模型请求，不修改本机防火墙。
